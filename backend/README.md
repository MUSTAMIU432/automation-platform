# Backend

This directory will contain the Django backend, organized as a modular
monolith around business domains (identity, organizations, ideas, reviews,
opportunities, proposals, developers, projects, tasks, notifications,
impact, files, audit).

**Status:** Not yet implemented. Scaffolding is planned for Sprint 0, task
S0-002 (Django Backend Foundation).

See [`/docs/architecture.md`](../docs/architecture.md) for the target
backend architecture.
